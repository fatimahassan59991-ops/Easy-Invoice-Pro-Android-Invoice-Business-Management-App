# Easy Invoice Pro

Easy Invoice Pro is an Android invoicing and small-business management application.

## Features

- Create and save invoices
- Automatic invoice numbering
- Customer and item management
- Payment method and payment status tracking
- Business profile and company logo support
- Review QR code support on receipts and invoices
- PDF invoice, receipt, and report generation
- Financial reports by day, month, and year
- Expense tracking
- Print and share support

## Development

### Prerequisites

- Android Studio
- Android SDK required by the project

### Run locally

1. Open Android Studio.
2. Select **Open** and choose this project folder.
3. Allow Gradle to sync and install any required SDK components.
4. Run the app on an Android emulator or a connected Android device.

## Release preparation

Before publishing a production release, review your signing configuration, privacy policy, payment integrations, permissions, and Google Play Data Safety information.
