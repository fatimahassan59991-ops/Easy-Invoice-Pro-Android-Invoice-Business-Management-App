# Easy Invoice Pro

A starter Android invoice app project.

## Included
- Automatic sequential invoice numbers (INV-0001, INV-0002, ...)
- Read-only invoice number
- Customer and product/service fields
- Quantity and price
- Automatic total calculation
- Payment methods:
  Cash, Credit Card, Debit Card, Check, Bank Transfer, ACH, Zelle,
  PayPal, Venmo, Apple Pay, Google Pay, Cash App, Stripe, Other
- Payment statuses:
  Unpaid, Partially Paid, Paid, Overdue
- Simple dashboard with paid and outstanding totals

## Open in Android Studio
1. Extract the ZIP.
2. Open Android Studio.
3. Choose **Open**.
4. Select the `easy-invoice-pro` folder.
5. Let Gradle sync.
6. Run on an Android emulator or phone.

## Important
This is a starter project. Before publishing to Google Play, add:
- persistent invoice/customer database
- PDF/receipt generation
- review QR upload and receipt placement
- proper app icon
- privacy policy/data safety disclosures
- signed release App Bundle (.aab)
